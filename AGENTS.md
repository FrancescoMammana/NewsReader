# Regole per Agent e Contributori

- **Workflow Git**: Lavorare sempre su branch dedicati. Eseguire `npm run build` e `npm run lint` prima del merge su `main`.
- **Qualità del Codice**:
  - Scrivere codice conciso ed evitare astrazioni o boilerplate inutili.
  - Riutilizzare funzioni, hook e componenti esistenti.
  - Mantenere file e componenti piccoli e focalizzati.
  - Prevenire le regressioni verificando build e lint.
- **Politica Linguistica**: Tutti i branch, i messaggi di commit, le PR e le note di merge devono essere scritti in **italiano**.
