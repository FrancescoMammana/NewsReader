# NewsReader — RSS & News Reader PWA

A modern, responsive Progressive Web Application (PWA) built with **React**, **TypeScript**, **Tailwind CSS**, and **Express** designed to aggregate, manage, and read any RSS or Atom feed with offline support.

## Features

- **Universal RSS / Atom Feed Management**: Add, remove, and reorder any external RSS or Atom feed URL as dedicated tabs alongside default news categories.
- **Responsive Split-View**: Dual-pane news feed and full article reader on desktop/tablet with expand/restore toggle, and stacked navigation on mobile.
- **Offline Reading Mode**: Download and cache articles and feeds locally for full offline reading anywhere.
- **Personal Article Notes & Comments**: Add personal notes, annotations, and comments to any article, stored securely in local storage.
- **Search, Filtering & Favorites**: Search articles by keyword, filter by date ranges, mark favorites, and export/import bookmarks.
- **Customizable Typography & Themes**: Choose from multiple font families (`Roboto Slab`, `Ubuntu`, `Ubuntu Mono`, `Noto Serif`, `Exo 2`, `Atkinson Hyperlegible`, `System Sans`), text scale factor, accent colors, and Light/Dark/True Dark Mode.
- **PWA Installable**: Install as a native-like app on desktop and mobile devices.
